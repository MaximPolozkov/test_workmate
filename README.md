# **cli приложение для обработки csv-файлов с метриками видео на YouTube.**

Что бы запустить приложение перейдите в терминал среды разработки и напишите команду:
"python main.py --files data/stats1.csv --report "Отчет по метрики"" если файлов несколько то
"python main.py --files data/stats1.csv data/stats2.csv --report "Анализ данных"",
где --files - название файла где находится скрипт а --report - название отчета. 

Для тестирования используются команды pytest --cov, poetry run pytest --cov, pytest --cov=src --cov-report=html.

Проект содержит виртуальное окружение poetry. После установки на локальный ПК запустить
команду poetry install то позволит установить все зависимости проекта.
